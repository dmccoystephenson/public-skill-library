# public-skill-library

An index of the [Claude Code](https://claude.com/claude-code) skills Daniel McCoy Stephenson has
published. Each skill lives in its own public repository; this repository only points to them.

A skill is a Markdown file of instructions that Claude Code runs as a slash command. Most of these
grew out of real work on the [Preponderous](https://github.com/Preponderous-Software),
[Stephenson Software](https://github.com/Stephenson-Software) and
[Dans Plugins](https://github.com/Dans-Plugins) projects, so some name tools from those
projects. Read a skill before running it.

## Installing a skill

Clone its repository and link the skill file into your commands folder:

```sh
git clone https://github.com/dmccoystephenson/nielsen-krug-pass.git ~/skills/nielsen-krug-pass
mkdir -p ~/.claude/commands
ln -s ~/skills/nielsen-krug-pass/nielsen-krug-pass.md ~/.claude/commands/nielsen-krug-pass.md
```

Then run `/nielsen-krug-pass` in Claude Code. The two zettelkasten skills are folders with a
`SKILL.md`, used from inside a clone of
[dpc-zettelkasten](https://github.com/Dans-Plugins/dpc-zettelkasten).

## Keeping the index accurate

`skills.json` is the list. `python3 tools/check_index.py --write` rebuilds the table above from it,
and `python3 tools/check_index.py` checks that the table is current and that every listed
repository is public and still has its skill file. CI runs the check on every push and once a week.
